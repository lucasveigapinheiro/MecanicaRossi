# Rossi Mecânica — Site institucional

![Rossi Mecânica — site no ar](imagens/rossi-preview.jpg)

No ar: https://lucasveigapinheiro.github.io/MecanicaRossi/

Site institucional da **Rossi Mecânica**, oficina real em São Bernardo do Campo com duas unidades. Apresenta os serviços, a história da oficina, depoimentos de clientes e leva o visitante direto ao WhatsApp para agendar.

## Destaques

- Seções de serviços, "o que o seu painel está dizendo?" (explicação das luzes do painel), história, depoimentos e unidades
- Botões de contato via WhatsApp em toda a página
- Página `sistema.html` com um protótipo de ordem de serviço salvo no navegador (LocalStorage) — a versão completa, com back-end, virou o projeto [sistemaos](https://github.com/lucasveigapinheiro/sistemaos)
- Layout responsivo

## Tecnologias

HTML5, CSS3, JavaScript (ES6+), LocalStorage.

## Como rodar

Abra o `index.html` no navegador ou sirva a pasta com:

```bash
npx serve .
```

## Estrutura

```
index.html     # Site institucional
sistema.html   # Protótipo de ordem de serviço
script.js      # Interações da página
style.css      # Estilos
imagens/       # Logo e arquivos da oficina
```
